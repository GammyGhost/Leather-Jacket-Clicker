# Leather Jacket CEO Clicker

This is a clicker game in which we have to click Leather Jacket CEO to unlock Old GPUs and Baddies

## Description

This is clicker game inspired by Boba Clicker in Boba Bash Delhi. In this Game we have to click a Leather Jacket CEO to earn AI Chips (Can be converted in SI Chips), these Chips can be used to buy new GPUs or pull up a Baddie or Chinese Spy!!
